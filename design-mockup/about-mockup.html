01我的路径

我的学习路径是从后端往 AI 方向走，而不是从脚本开始。这个顺序影响了我做 Agent 的方式： 我会先问「这条链路在生产上会不会断」，再问「效果好不好」。

第一步 · Java 工程基础

高并发与分布式系统

基于 SpringBoot 的生活服务平台，在秒杀主链路上完成了四轮演进：阻塞队列 → Redis + Lua 原子扣减 → Redisson 分布式锁 → Kafka 异步削峰。理解了「并发安全」不只是加锁。

第二步 · 微服务架构

16 模块的在线教育系统

按模块独立实现并调试完整的微服务体系：网关、鉴权、消息、交易、促销、搜索。覆盖 Redis BitMap、XXL-JOB 跑批、RabbitMQ 可靠消息、CompletableFuture 并发编排。

第三步 · 正在做

Agent 应用工程化

从给现有 Java 系统加一个 AI 客服模块开始，到独立完成一个多章节递进的客服 Agent 项目。关注点从「能不能跑通」转向「断不断、幂不幂等、降不降级」。
